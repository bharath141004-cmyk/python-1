# 🐍 Python Practice Programs

A collection of beginner-friendly **Python programs and practice exercises** covering fundamental Python concepts such as lists, operators, calculations, and basic problem solving.

## 📌 About the Project

This repository contains simple Python programs created for learning and practicing Python programming.

The examples focus on understanding basic programming concepts through practical problems and small exercises.

## 📚 Programs Included

The repository currently contains the following programs:

### 1. 🧮 Bitwise Operators

Demonstrates the use of Python bitwise operators such as:

* AND `&`
* OR `|`
* XOR `^`
* Left Shift `<<`
* Right Shift `>>`

### 2. 🔍 Identity Operators

Demonstrates Python identity operators:

* `is`
* `is not`

These operators are used to check whether two variables refer to the same object.

### 3. 📝 Adding Elements to a List

Demonstrates how to add elements to a Python list using list methods.

### 4. ⚡ Electricity Bill Calculator

A simple Python program that calculates an electricity bill based on the given electricity usage.

### 5. 📊 Marks List

Demonstrates working with a list of marks, for example:

```python
marks = [80, 90, 75]
```

It helps in understanding Python lists and basic list operations.

### 6. ❌ Removing Elements from a List

Demonstrates different ways to remove elements from a Python list.

### 7. ✈️ Travel Expense Calculator

A simple program for calculating travel expenses based on the given values.

## ▶️ How to Run

### 1. Install Python

Make sure **Python 3** is installed on your computer.

### 2. Clone the Repository

```bash
git clone https://github.com/bharath141004-cmyk/python-1.git
```

### 3. Open the Repository

```bash
cd python-1
```

### 4. Run a Python Program

For a Python file, use:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python program you want to run.
